# TravelSafe-Bus-Booking

![TravelSafe Bus Services](images/bus.jpg)

## 📌 Project Overview

TravelSafe Bus Booking System is a responsive web-based bus ticket booking application developed using **HTML, CSS and JavaScript**.

The system allows customers to enter their personal information, select a departure and destination, choose a travel date, select a morning or night departure, select a seat and receive a **booking confirmation ticket by email**.

The project was developed as a portfolio project to demonstrate practical skills in **frontend development, JavaScript programming, Git/GitHub and third-party service integration**.

## ✨ Features

### 🎫 Online Bus Booking

* Customer registration through a booking form
* Passenger information collection
* Departure and destination selection
* Travel date selection
* Morning and night departure options

### 🚌 Bus Routes

The system currently supports multiple South African routes, including:

* Johannesburg → Durban — R450
* Durban → Johannesburg — R450
* Johannesburg → Cape Town — R900
* Cape Town → Johannesburg — R900
* Johannesburg → Pretoria — R120
* Pretoria → Johannesburg — R120
* Johannesburg → Bloemfontein — R500
* Bloemfontein → Johannesburg — R500
* Johannesburg → Gqeberha — R750
* Gqeberha → Johannesburg — R750
* Durban → Cape Town — R700
* Cape Town → Durban — R700
* Pretoria → Durban — R500
* Durban → Pretoria — R500

### 🕘 Bus Schedules

Customers can choose between:

* ☀️ Morning — 09:00 AM
* 🌙 Night — 08:00 PM

### 💺 Seat Selection

* 60 available seat positions
* Customers can select their preferred seat
* Selected seats are visually highlighted
* Some seats can be marked as unavailable/booked

### 💰 Automatic Ticket Pricing

The ticket price is automatically calculated according to the selected route.

For example:

`Johannesburg → Durban = R450`

### 🔖 Booking Reference

Every successful booking receives a unique booking reference such as:

`TS-583421`

### 📧 Email Ticket Confirmation

The system uses **EmailJS** to send the customer's booking confirmation directly to the email address entered during the booking process.

The email contains:

* Passenger name
* Email address
* Phone number
* Age
* Departure city
* Destination
* Travel date
* Travel period
* Departure time
* Seat number
* Ticket price
* Booking reference
